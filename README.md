# Data Center Equipment Monitoring

## 📌 Sujet du stage

**Analyse des données de maintenance des équipements critiques d’un Data Center pour l’amélioration de la maintenance prédictive.**

## 🎯 Objectif

Développer une solution de supervision permettant de collecter, nettoyer, stocker et visualiser les données issues des équipements critiques d’un Data Center afin de faciliter le suivi de leurs performances et la détection des anomalies.

## 🛠️ Technologies utilisées

* **Python**
* **PostgreSQL**
* **Grafana**
* **Docker**
* **Kubernetes**
* **SQL**

## 🔄 Architecture

**Équipements → Collecte des données → Nettoyage & traitement → PostgreSQL → Grafana**

## 📊 Fonctionnalités

* Collecte des données de supervision des équipements
* Nettoyage et traitement des données
* Stockage des données dans PostgreSQL
* Création de dashboards de monitoring avec Grafana
* Suivi des performances des équipements
* Détection des anomalies
* Conteneurisation avec Docker
* Déploiement avec Kubernetes

## 🏢 Contexte

Projet réalisé dans le cadre d’un stage chez **CIRES Technologies** en 2026.
